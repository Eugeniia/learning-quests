### Введение в язык программирования Go (Golang)
В основе языка Golang — база лучших функций из языков C и C++, Python, Pascal, Oberon и Modula. Сначала Go использовали внутри Google, но затем он стал применяться в компаниях по всему миру: HP, Adobe, Microsoft, Facebook, BBC, Uber, Dropbox, Netflix, Яндекс, ВКонтакте, Avito, Ozon и других.

Через пару лет работы Google создала Go: язык, на котором код пишется быстро, а полученные программы легко компилируются и выполняются. В 2009 году проект перешел на лицензию с открытым исходным кодом. Сейчас этот язык могут свободно использовать все желающие.

https://go.dev/solutions/google/

Интегрированная среда разработки (IDE) для Go:
1) GoLand
2) Visual Studio Code
3) LiteIDE 
4) GoClipse
5) Vim. Основной плагин для поддержки Go — vim-go, который предоставляет базовые функции для работы с языком. Для расширенных возможностей, таких как автодополнение, линтинг и форматирование, часто используют дополнительные инструменты, например gopls (язык-сервер Go).
git clone https://github.com/fatih/vim-go.git ~/.vim/pack/plugins/start/vim-go
После установки необходимо выполнить команду :GoInstallBinaries в Vim, чтобы установить все необходимые бинарные файлы.
